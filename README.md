# Apiway plugin for Claude Code and Codex

Connects the agent to Apiway (the MCP server) with two skills: `apiway-apps` — build Apiway apps
(create, brief, update the preview, publish when the person asks) — and `apiway-workspace` — work in
the person's account (mail, tasks, email marketing, automations, memory, generation), with sending and
deleting only on the person's explicit yes.

## Install

Claude Code:

```
/plugin marketplace add apiway-ai/apiway-plugins
/plugin install apiway@apiway
```

ChatGPT and Codex: Apiway is in their plugin directory as «Apiway — AI Workspace» — open
https://chatgpt.com/plugins/plugin_asdk_app_6ac1b80c1e7c8191ab90cb41923ce43d (or Customize → Plugins → search Apiway),
press Connect / +, sign in to Apiway and press Allow.

Cursor has no plugin format for this — Apiway gives a one-click "Add to Cursor" link instead.

This folder is generated by `scripts/code-apps/build-plugin.ts` from `app-kit/plugin/` in the Apiway
repository; the skill text comes from the app kit's AGENTS.md so the two never drift apart.
